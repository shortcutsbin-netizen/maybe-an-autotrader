# maybe-an-autotrader

A research project to find out whether an autonomous, LLM-free Python bot can earn a repeatable edge on Kalshi's short-duration markets (mainly 15-minute crypto up/down contracts) — and to build one only if the evidence supports it.

**Status:** Phase 1 (research and planning). No trading code exists. Nothing here places orders.
